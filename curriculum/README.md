# Ханзи BG — учебна пътека

Тук са **ръчно написаните** файлове на учебната програма. Те не се
генерират и не се презаписват от pipeline-а: редът, в който ученикът
среща думите, е педагогическо решение, а не свойство на корпуса.

## Файловете

| Файл | Какво е |
|---|---|
| `00_intro.json` | Двата урока за звука: пиньин и четирите тона. Те са карти, а не думи. |
| `10_hsk1.json` | 17 теми, 34 урока, 300-те думи от HSK 1, подредени за начинаещ. |
| `20_glosses_hsk1.json` | Ръчно написани български глоси за 300-те думи. |
| `30_situations.json` | Тема „Ситуации“: уроци за четене — кратки разговори, въпрос за всеки и превод на реда зад бутон „?“. |

## Форматът

Два различни формата се четат от `pipeline/08_build_content_db.py`, и
се различават по съдържанието, не по името:

**Учебна пътека** — обект с ключ `units`:

```json
{
  "units": [
    {
      "key": "numbers",
      "title": "Числа",
      "lessons": [
        {
          "key": "numbers-1",
          "title": "Числа от 1 до 10",
          "words": ["一", "二", "三"]
        }
      ]
    }
  ]
}
```

Урокът с `"kind": "teach"` носи `cards` вместо `words`. Картата е:

```json
{
  "kind": "text" | "items" | "table" | "reading",
  "title": "Заглавие",
  "body": "Обяснение",
  "items": [{ "hanzi": "你好", "pinyin": "nǐ hǎo", "text": "здравей" }],
  "rows": [["b", "p"], ["d", "t"]]
}
```

Картата `"reading"` е пасаж — кратък разговор за четене:

```json
{
  "kind": "reading",
  "title": "На пазара",
  "body": "Прочети съобщението и отговори на въпроса.",
  "lines": [
    {
      "hanzi": "我要三个苹果。",
      "pinyin": "Wǒ yào sān gè píngguǒ.",
      "bg": "Искам три ябъка.",
      "audio": "reading_market_1.ogg"
    }
  ],
  "question": {
    "text": "Какво иска купувачът?",
    "options": ["Три ябъка", "Пет мандарина", "Десет ябъка"],
    "answer": 0
  }
}
```

`bg` е джокерът: преводът на реда се отваря с бутона „?“ и не се
показва преди въпроса. `audio` е името на клипа, който
`pipeline/13_build_reading_audio.py` записва в `data/audio/` — името е
договор между ръчно написания файл и pipeline-а.

**Патч с глоси** — плосък обект `йероглиф → български текст`. Той
**презаписва** машинния превод за посочените думи и те се маркират
като човешки в базата.

## Правилата

1. Всеки урок носи **8 до 10 думи**.
2. Ключовете са уникални в целия файл; ключът на урока започва с
   ключа на темата.
3. Всяка дума трябва да съществува в речника. Ако не —
   `08_build_content_db.py` спира с грешка, а не пише счупена база.
4. Заглавията са на български, кратки, без точка в края.
5. Глосите са **къси** (до 45 знака), без скоби и без „/“ — така
   формата, в който машинният превод е натрупал всичките си значения,
   не се повтаря.

## Проверка

```bash
python pipeline/08_build_content_db.py
```

Скриптът спира, ако пътеката е празна или ако някой урок назовава
дума, която речникът няма. Всичко, което е в `curriculum/`, трябва да
е в git — `data/` е gitignored и се презаписва при build.
